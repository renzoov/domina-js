## break: salir del bucle

`break` **termina el bucle** en el acto, aunque queden vueltas. El programa sigue con la línea de después del bucle. Es útil cuando ya encontraste lo que buscabas:

```js
const invitados = ["Ana", "Luis", "Marta", "Pedro"];

for (const nombre of invitados) {
  if (nombre === "Marta") {
    console.log("¡Marta está invitada!");
    break;  // no hace falta seguir mirando
  }
  console.log(`${nombre} no es Marta`);
}
```

## continue: saltar a la siguiente vuelta

`continue` **abandona solo la vuelta actual** y pasa a la siguiente. Sirve para ignorar los elementos que no te interesan sin meter el resto del código dentro de un `if`:

```js
const temperaturas = [22, -999, 25, 19, -999, 30];  // -999 = sensor sin dato

for (const t of temperaturas) {
  if (t === -999) continue;  // ignora los datos inválidos
  console.log(`${t} °C`);
}
```

En un `for` clásico, `continue` igual ejecuta el paso (`i++`) antes de la siguiente vuelta, así que no se queda trabado.

## Bucles anidados y etiquetas

Con un bucle dentro de otro, `break` y `continue` afectan solo al **más cercano**. Para controlar el de afuera, ponle una **etiqueta**: un nombre seguido de dos puntos, justo delante del bucle.

```js
const tablero = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9],
];

buscar: for (const fila of tablero) {
  for (const celda of fila) {
    if (celda === 5) {
      console.log("Encontré el 5");
      break buscar;  // sale de los DOS bucles
    }
  }
}
console.log("Búsqueda terminada");
```

Sin la etiqueta, el `break` solo saldría del bucle de adentro, y el de afuera seguiría con la fila siguiente.

<Nota tipo="consejo">
  Las etiquetas casi no se usan en código moderno. Cuando las necesites, piensa si no quedaría más claro meter los bucles en una **función** y usar `return` para salir de todo. Lo vas a ver en la sección de Funciones.
</Nota>

## Dónde no van

- `break` solo funciona dentro de un **bucle** o de un **`switch`**.
- `continue` solo funciona dentro de un **bucle**.
- Dentro de un `if` suelto, cualquiera de los dos es un error de sintaxis: el bloque del `if` termina solo.
- Para dejar de ejecutar una función, lo que buscas es `return`.

## Resumen

- `break` termina el bucle (o el `switch`) y el programa sigue después.
- `continue` salta el resto de la vuelta actual y pasa a la siguiente.
- En bucles anidados, actúan sobre el bucle **más cercano**. Con una **etiqueta** (`afuera:`) puedes apuntar a uno exterior.
- Fuera de un bucle o `switch` son un error. Para salir de una función, `return`.
