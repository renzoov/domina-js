## Declaración

La forma clásica: la palabra `function`, un nombre, los parámetros entre paréntesis y el cuerpo entre llaves.

```js
function areaRectangulo(base, altura) {
  return base * altura;
}

console.log(areaRectangulo(3, 4));
```

`return` termina la función y entrega un valor a quien la llamó. Las declaraciones se **elevan completas** (lo viste en *Contextos de ejecución y hoisting*): puedes llamarlas antes de la línea donde están escritas.

## Expresión de función

Una función también es un **valor**, así que puedes crearla en medio de una expresión y guardarla en una variable:

```js
const areaCirculo = function (radio) {
  return Math.PI * radio ** 2;
};

console.log(areaCirculo(1).toFixed(2));
```

Funciona igual, pero sigue las reglas de `const`: no se puede usar antes de su línea. La expresión puede tener nombre propio (`function calcular(…)`), útil para que aparezca en la pila de llamadas al depurar.

## Funciones flecha

Desde ES2015, la forma más corta: sin la palabra `function`, con una flecha `=>` entre los parámetros y el cuerpo.

```js
const cuadrado = (n) => n * n;          // un parámetro, una expresión
const sumar = (a, b) => a + b;           // dos parámetros
const saludar = () => "¡Hola!";          // sin parámetros
const describir = (nombre, edad) => {    // varias instrucciones: con llaves
  const etapa = edad >= 18 ? "adulto" : "menor";
  return `${nombre} es ${etapa}`;
};

console.log(cuadrado(5), sumar(2, 3), saludar());
console.log(describir("Ana", 31));
```

Las reglas del cuerpo:

- **Sin llaves**: el resultado de la expresión se devuelve solo. Es el **retorno implícito**.
- **Con llaves**: es un bloque normal y necesita `return`.
- **Para devolver un objeto** sin `return`, envuélvelo en paréntesis: `() => ({ ok: true })`. Si no, las llaves se leen como un bloque.

## Sin return

Una función que termina sin `return`, o con un `return` vacío, devuelve `undefined`:

```js
function avisar(texto) {
  console.log("Aviso:", texto);
}

const resultado = avisar("guardado");
console.log(resultado);
```

<Nota tipo="error">
  El error más común con las flechas: agregar llaves a una flecha de una línea y olvidar el `return`. `(n) => { n * 2 }` devuelve `undefined`.
</Nota>

## ¿Cuál uso?

| Forma | Úsala para |
|---|---|
| `function nombre() {}` | Funciones principales de un archivo, con nombre propio |
| `const f = () => …` | Funciones cortas y callbacks (`map`, `filter`, eventos) |
| `function` dentro de un objeto | Métodos que usan `this`; las flechas no sirven ahí (lo verás en *this*) |

Hay una diferencia más, importante: las flechas **no tienen `this` propio**. Lo vas a ver en el tema *this: cómo se decide su valor*.

## Resumen

- Tres formas: **declaración**, **expresión** y **flecha**. Las tres crean un valor de tipo `function`.
- Solo las declaraciones se pueden llamar antes de su línea.
- Las flechas sin llaves tienen **retorno implícito**; con llaves, necesitan `return`.
- Para devolver un objeto desde una flecha: `() => ({ … })`.
- Sin `return`, una función devuelve `undefined`.
