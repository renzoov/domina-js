## function* y yield

Una función generadora se escribe con un asterisco. Dentro, `yield` entrega un valor y pausa:

```js
function* semaforo() {
  yield "verde";
  yield "amarillo";
  yield "rojo";
}

const s = semaforo();
console.log(s.next());
console.log(s.next().value);

for (const luz of semaforo()) {
  console.log(luz);
}
```

Llamar a `semaforo()` no ejecuta nada: devuelve un **generador**, que es a la vez un **iterador** (tiene `next()`) y un **iterable** (funciona con `for...of`). Como viste en el pizarrón, el cuerpo avanza solo hasta el siguiente `yield` cada vez que alguien pide un valor.

## Lo que ahorra

El rango del tema anterior, con un generador:

```js
function* rango(desde, hasta) {
  for (let n = desde; n <= hasta; n++) {
    yield n;
  }
}

console.log([...rango(1, 5)]);
```

Y como método iterable de un objeto, con la sintaxis `*[Symbol.iterator]()`:

```js
const playlist = {
  canciones: ["Intro", "Tema 1", "Final"],
  *[Symbol.iterator]() {
    for (const c of this.canciones) yield `♪ ${c}`;
  },
};

console.log([...playlist]);
```

## Secuencias infinitas

Como un generador solo avanza cuando le piden un valor, puede describir secuencias **sin fin**:

```js
function* fibonacci() {
  let [a, b] = [0, 1];
  while (true) {
    yield a;
    [a, b] = [b, a + b];
  }
}

const fib = fibonacci();
const primeros = [];
for (let i = 0; i < 10; i++) primeros.push(fib.next().value);
console.log(primeros);
```

<Nota tipo="error">
  Nunca consumas entero un generador infinito: `[...fibonacci()]` o `for (const x of fibonacci())` sin un `break` no terminan nunca. En el próximo tema, `take` lo resuelve con elegancia.
</Nota>

## yield* para delegar

`yield*` entrega, uno por uno, todos los valores de otro iterable o generador:

```js
function* vocales() {
  yield* "aeiou";
}

function* abecedarioCorto() {
  yield "inicio";
  yield* vocales();
  yield* [1, 2];
  yield "fin";
}

console.log([...abecedarioCorto()].join(" "));
```

Es útil para recorrer estructuras recursivas, como un árbol:

```js
function* recorrer(nodo) {
  yield nodo.nombre;
  for (const hijo of nodo.hijos) yield* recorrer(hijo);
}

const carpeta = { nombre: "src", hijos: [{ nombre: "app.js", hijos: [] }, { nombre: "lib", hijos: [{ nombre: "util.js", hijos: [] }] }] };
console.log([...recorrer(carpeta)]);
```

## return en un generador

Un `return` termina el generador. Su valor aparece en el último `next()`, con `done: true`, pero `for...of` y el spread lo **ignoran**:

```js
function* corto() {
  yield 1;
  return 99;
}

const g = corto();
console.log(g.next(), g.next());
console.log([...corto()]);
```

## Resumen

- `function*` define un generador; llamarlo no ejecuta nada.
- `yield valor` entrega el valor y **pausa**; `next()` **retoma** donde quedó.
- Un generador es iterador e iterable a la vez, y de **un solo uso**.
- Pueden ser infinitos: solo avanzan cuando les piden valores.
- `yield*` delega en otro iterable; `return` termina, y su valor no se recorre.
