## Las novedades

| Novedad | Qué hace | Se explica en |
|---|---|---|
| `Map.prototype.getOrInsert` y `getOrInsertComputed` | Leer una entrada o crearla si falta (*upsert*) | [Map y Set](/colecciones/map-y-set) |
| Base64 y hexadecimal en `Uint8Array` | `toBase64`, `fromBase64`, `toHex`, `fromHex` | [Datos binarios](/colecciones/datos-binarios) |
| `Math.sumPrecise` | Sumar sin acumular errores de redondeo | [Números](/fundamentos/numeros) |
| `Error.isError` | ¿Es un error de verdad? Funciona entre realms | [Errores y excepciones](/control-de-flujo/errores-y-excepciones) |
| `Array.fromAsync` | `Array.from` para iterables asíncronos | [Iteración asíncrona](/iteradores/iteracion-asincrona) |
| `Iterator.concat` | Recorrer varios iterables seguidos | [Iterator helpers](/iteradores/iterator-helpers) |

## En una mirada

```js
const porLetra = new Map();
for (const palabra of ["sol", "sal", "mar"]) {
  porLetra.getOrInsertComputed(palabra[0], () => []).push(palabra);
}
console.log(porLetra);

const bytes = Uint8Array.fromHex("4a53");
console.log(bytes, bytes.toBase64());

console.log(Math.sumPrecise([1e20, 1, -1e20]), 1e20 + 1 - 1e20);

async function* lento() { yield 1; yield 2; }
console.log(await Array.fromAsync(lento()));

console.log(Iterator.concat([1, 2], new Set([3])).toArray());
```

## Resumen

- `getOrInsert` y `getOrInsertComputed` en `Map`.
- `Uint8Array` con base64 y hexadecimal.
- `Math.sumPrecise`, `Error.isError`, `Array.fromAsync` e `Iterator.concat`.
