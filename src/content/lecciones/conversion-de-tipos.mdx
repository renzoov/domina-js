## Implícita y explícita

Hay dos formas de convertir un valor de un tipo a otro:

- **Implícita** (o *coerción*): el motor la hace solo, cuando una operación necesita otro tipo. No la ves en el código.
- **Explícita**: la escribes tú, con `Number()`, `String()` o `Boolean()`. Queda claro qué pasa.

La regla de oro: **convierte explícitamente**. El código se lee mejor y no depende de que recuerdes las reglas de la coerción.

## A número

```js
console.log(Number("42"));       // 42
console.log(Number("3.5"));      // 3.5
console.log(Number("12px"));     // NaN: todo el texto debe ser un número
console.log(Number(""));         // 0 (¡ojo!)
console.log(Number(true));       // 1
console.log(Number(null));       // 0
console.log(Number(undefined));  // NaN
```

Para leer un número **al principio** de un texto, como `"12px"` o `"3.5 kg"`, usa `parseInt` (enteros) o `parseFloat` (decimales). Leen desde el inicio y se detienen en el primer carácter que no entienden:

```js
console.log(parseInt("12px"));        // 12
console.log(parseFloat("3.5 kg"));    // 3.5
console.log(parseInt("ff", 16));      // 255: el segundo argumento es la base
console.log(parseInt("hola"));        // NaN
```

El `+` delante de un valor (*+ unario*) también convierte a número: `+"42"` da `42`. Es corto, pero menos legible que `Number()`.

## A texto y a booleano

```js
console.log(String(42));          // "42"
console.log(String(null));        // "null"
console.log(String([1, 2, 3]));   // "1,2,3"
console.log((255).toString(16));  // "ff"

console.log(Boolean("hola"));     // true
console.log(Boolean(0));          // false
```

Para booleanos se aplica la regla de truthy y falsy que viste en el tema anterior.

## La trampa del +

Es lo que muestra el pizarrón. `+` tiene dos trabajos: **sumar** números y **concatenar** textos. Si **cualquiera** de los dos lados es un texto, concatena:

```js
console.log("5" + 2);        // 52
console.log(1 + 2 + "3");    // 33: primero 1 + 2 = 3, después "3" + "3"
console.log("1" + 2 + 3);    // 123: desde el principio es texto
```

Los demás operadores aritméticos (`-`, `*`, `/`, `%`) solo trabajan con números, así que **convierten** los textos:

```js
console.log("10" - 4);   // 6
console.log("10" * "2"); // 20
console.log("a" * 2);    // NaN: "a" no se puede convertir
```

<Nota tipo="error">
  El error más común de coerción: sumar datos de un formulario. `campo1.value + campo2.value` concatena, porque los campos siempre devuelven texto. Convierte cada valor con `Number()` en cuanto lo leas.
</Nota>

## == frente a ===

JavaScript tiene dos operadores de igualdad:

- **`===`** (igualdad estricta): si los tipos son distintos, da `false` sin convertir nada.
- **`==`** (igualdad amplia): **convierte** antes de comparar, con reglas difíciles de recordar.

```js
console.log(0 === "");        // false
console.log(0 == "");         // true
console.log("1" == 1);        // true
console.log(false == "0");    // true
console.log(null == undefined); // true
console.log(null == 0);       // false
```

Por resultados como estos, **usa siempre `===` y `!==`**. Muchos equipos tienen una regla en su linter que prohíbe `==`. La única excepción que vas a ver en código ajeno es `valor == null`, un atajo para preguntar "¿es `null` o `undefined`?" a la vez.

## Resumen

- La conversión **implícita** la hace el motor solo; la **explícita** la escribes tú. Prefiere la explícita.
- `Number()` convierte el texto entero (o da `NaN`); `parseInt` y `parseFloat` leen el número del principio.
- Ojo: `Number("")` da `0`, no `NaN`.
- Con un texto de por medio, `+` **concatena**; `-`, `*`, `/` y `%` **convierten** a número.
- Usa siempre `===` y `!==`: `==` convierte antes de comparar y da sorpresas.
