## Funciones puras

Una función es **pura** si cumple dos condiciones:

1. Con los **mismos argumentos**, devuelve **siempre lo mismo**.
2. No tiene **efectos secundarios**: no modifica nada fuera de ella.

```js
// Pura: solo depende de sus argumentos
const conDescuento = (precio, porcentaje) => precio * (1 - porcentaje / 100);

// Impura: depende de una variable externa que puede cambiar
let descuentoGlobal = 10;
const conDescuentoGlobal = (precio) => precio * (1 - descuentoGlobal / 100);

console.log(conDescuento(100, 10));
console.log(conDescuentoGlobal(100));
descuentoGlobal = 50;
console.log(conDescuentoGlobal(100));  // mismo argumento, otro resultado
```

Los **efectos secundarios** son modificar argumentos o variables externas, imprimir, guardar datos, hacer peticiones… Un programa sin ellos no serviría para nada. La idea no es eliminarlos, sino **concentrarlos** en pocos lugares y mantener puro todo lo demás.

## No mutar

Una función pura no modifica lo que recibe: devuelve un valor nuevo.

```js
// Mutante: cambia el array de quien la llama
function agregarMal(lista, item) {
  lista.push(item);
  return lista;
}

// Pura: devuelve un array nuevo
const agregar = (lista, item) => [...lista, item];

const original = ["pan"];
const nueva = agregar(original, "leche");
console.log(original, nueva);
```

## map, filter y reduce

Los tres métodos estrella para transformar listas sin bucles ni mutaciones:

- **`map(fn)`**: transforma cada elemento. Devuelve un array del **mismo largo**.
- **`filter(fn)`**: se queda con los elementos para los que `fn` devuelve `true`.
- **`reduce(fn, inicial)`**: combina todos los elementos en **un solo valor**.

```js
const productos = [
  { nombre: "Teclado", precio: 45, stock: 3 },
  { nombre: "Ratón", precio: 20, stock: 0 },
  { nombre: "Monitor", precio: 180, stock: 5 },
];

const disponibles = productos
  .filter((p) => p.stock > 0)
  .map((p) => p.nombre);

const valorInventario = productos.reduce((total, p) => total + p.precio * p.stock, 0);

console.log(disponibles);
console.log(valorInventario);
```

Cada paso devuelve un array nuevo, así que se pueden **encadenar**, y la cadena se lee de arriba abajo como una receta.

<Nota tipo="error">
  Dale siempre un valor inicial a `reduce`. Sin él, usa el primer elemento como acumulador, y con un array vacío lanza `TypeError: Reduce of empty array with no initial value`.
</Nota>

## Componer funciones

**Componer** es unir funciones pequeñas para que la salida de una sea la entrada de la siguiente. Con una función auxiliar `pipe`, que aplica una lista de funciones en orden, quedan transformaciones muy legibles:

```js
const pipe = (...fns) => (valor) => fns.reduce((acum, fn) => fn(acum), valor);

const limpiar = (t) => t.trim();
const minusculas = (t) => t.toLowerCase();
const aSlug = (t) => t.replaceAll(" ", "-");

const crearSlug = pipe(limpiar, minusculas, aSlug);
console.log(crearSlug("  Hola Mundo JS  "));
```

## Aplicación parcial

Una función que devuelve otra te deja **fijar** algunos argumentos de antemano y completar el resto después. Es la idea de las fábricas que viste en *Closures*:

```js
const multiplicar = (a) => (b) => a * b;

const doble = multiplicar(2);
const triple = multiplicar(3);

console.log([1, 2, 3].map(doble));
console.log([1, 2, 3].map(triple));
```

## Currificación

**Currificar** es convertir una función de varios parámetros en una cadena de funciones de un parámetro: `f(a, b, c)` pasa a ser `f(a)(b)(c)`. Es la aplicación parcial llevada a todos los parámetros, y se puede hacer con una función que envuelve a cualquier otra:

```js
const curry = (fn) =>
  function curried(...args) {
    // si ya llegaron todos los argumentos que espera fn, la llama; si no, espera más
    return args.length >= fn.length ? fn(...args) : (...mas) => curried(...args, ...mas);
  };

const saludar = (saludo, signo, nombre) => `${saludo}, ${nombre}${signo}`;
const hola = curry(saludar)("Hola");

console.log(hola("!")("Ana"));
console.log(["Luis", "Marta"].map(hola("?")));
console.log(curry(saludar)("Chau", ".", "Sofía"));
```

Fíjate en el orden de los parámetros: lo que se fija antes (el saludo) va primero, y **el dato va al final**. Así `hola("?")` queda lista para pasarla a `map`.

`fn.length` cuenta solo los parámetros sin valor por defecto y antes de un `...rest`, así que `curry` no sirve para esas funciones. En JavaScript la currificación se usa menos que en otros lenguajes: muchas veces una flecha (`(nombre) => saludar("Hola", "!", nombre)`) se lee más fácil.

## Cambios profundos sin mutar

Con datos anidados, como el estado de una aplicación, no mutar significa copiar **solo el camino** hasta lo que cambia. Lo demás se **comparte** entre la versión vieja y la nueva:

```js
const estado = { usuario: { nombre: "Ana", ajustes: { tema: "oscuro", idioma: "es" } }, carrito: [1, 2] };

const nuevo = {
  ...estado,
  usuario: { ...estado.usuario, ajustes: { ...estado.usuario.ajustes, tema: "claro" } },
};

console.log(nuevo.usuario.ajustes.tema, estado.usuario.ajustes.tema);
console.log(nuevo.carrito === estado.carrito, nuevo.usuario === estado.usuario);
```

Compartir lo que no cambió ahorra memoria y tiene una ventaja más: para saber si algo cambió, basta comparar referencias (`nuevo.carrito === estado.carrito`), sin recorrerlo. Muchas librerías de interfaz se basan en eso. Cuando el anidado es muy profundo, librerías como Immer te dejan escribir el cambio "como si mutaras" y arman la copia por ti. (Las formas de congelar objetos las viste en *Inmutabilidad*.)

## Resumen

- Una función **pura** depende solo de sus argumentos y no cambia nada de afuera.
- Concentra los **efectos secundarios** en pocos lugares; mantén puro el resto.
- No mutes: devuelve valores nuevos con spread, `map`, `filter`, `toSorted`…
- `map` transforma, `filter` selecciona, `reduce` combina. Siempre con valor inicial en `reduce`.
- **Componer** y **aplicar parcialmente** construyen funciones complejas a partir de piezas simples.
- **Currificar**: `f(a, b, c)` pasa a ser `f(a)(b)(c)`; el dato va al final.
- Con datos anidados, copia solo el camino hasta el cambio y comparte el resto.
