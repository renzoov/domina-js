## Las novedades

| Novedad | Qué hace | Se explica en |
|---|---|---|
| *Iterator helpers* e `Iterator.from` | `map`, `filter`, `take`, `drop`, `toArray`… en iteradores, perezosos | [Iterator helpers](/iteradores/iterator-helpers) |
| Métodos de `Set` | `union`, `intersection`, `difference`, `symmetricDifference`, `isSubsetOf`… | [Map y Set](/colecciones/map-y-set) |
| Módulos JSON y atributos de importación | `import datos from "./x.json" with { type: "json" }` | [JSON](/objetos/json) e [Import maps](/modulos/import-maps) |
| `RegExp.escape` | Usar un texto literal dentro de una regex | [Expresiones regulares](/biblioteca-estandar/expresiones-regulares) |
| Modificadores de regex `(?i:…)` | Activar banderas solo en una parte | [Expresiones regulares](/biblioteca-estandar/expresiones-regulares) |
| Grupos con nombre repetidos | El mismo nombre en alternativas distintas | [Expresiones regulares](/biblioteca-estandar/expresiones-regulares) |
| `Promise.try` | Convertir también los errores síncronos en rechazos | [Combinadores de promesas](/asincronia/combinadores) |
| `Float16Array` y `Math.f16round` | Decimales de media precisión | [Datos binarios](/colecciones/datos-binarios) |

## En una mirada

```js
function* naturales() {
  let n = 1;
  while (true) yield n++;
}
console.log(naturales().filter((n) => n % 3 === 0).take(3).toArray());

const frontend = new Set(["js", "css", "html"]);
const backend = new Set(["js", "sql"]);
console.log(frontend.union(backend).size, [...frontend.difference(backend)]);

console.log(/(?i:hola) Mundo/.test("HOLA Mundo"), RegExp.escape("a.b").endsWith("\\.b"));
console.log(new Float16Array([1.1])[0]);
```

## Resumen

- *Iterator helpers*: los métodos de los arrays, perezosos, en cualquier iterador.
- Operaciones de conjuntos en `Set`.
- Módulos JSON con atributos de importación.
- `RegExp.escape`, modificadores y grupos con nombre repetidos.
- `Promise.try` y `Float16Array`.
