## for: repetir un número de veces

El `for` clásico tiene tres partes entre paréntesis, separadas por `;`:

```js
for (let i = 0; i < 5; i++) {
  console.log(`Vuelta número ${i}`);
}
```

1. **Inicio** (`let i = 0`): se ejecuta una sola vez, antes de empezar.
2. **Condición** (`i < 5`): se comprueba **antes** de cada vuelta. Si es falsa, el bucle termina.
3. **Paso** (`i++`): se ejecuta **después** de cada vuelta.

Por convención, el contador se llama `i` y empieza en 0, porque los índices de los arrays empiezan en 0.

## for…of: recorrer valores

Para recorrer los elementos de un array, o las letras de un texto, `for…of` es más claro: te da directamente cada valor, sin índices.

```js
const compras = ["pan", "leche", "huevos"];

for (const producto of compras) {
  console.log(`Comprar ${producto}`);
}

for (const letra of "hola") {
  console.log(letra);
}
```

Usa `const` en `for…of`: en cada vuelta se crea una variable nueva, así que no hace falta `let`. Si además necesitas el índice, usa `compras.entries()`: `for (const [i, producto] of compras.entries())`.

## for…in: recorrer las claves de un objeto

`for…in` recorre las **claves** de un objeto:

```js
const precios = { pan: 1.2, leche: 0.9 };

for (const producto in precios) {
  console.log(`${producto}: ${precios[producto]} €`);
}
```

<Nota>
  No uses `for…in` con arrays: te da los índices como **texto** (`"0"`, `"1"`…) y puede incluir propiedades heredadas. Para arrays, `for…of`. Para objetos, también puedes usar `Object.entries(objeto)` con `for…of`, que verás en la sección de Objetos.
</Nota>

## while y do…while: repetir mientras

`while` repite **mientras** una condición sea verdadera. Es útil cuando no sabes de antemano cuántas vueltas harán falta:

```js
let saldo = 100;
let meses = 0;

while (saldo < 200) {
  saldo = saldo * 1.1;
  meses++;
}

console.log(`El saldo se duplica en ${meses} meses`);
```

`do…while` es igual, pero comprueba la condición **al final**: el cuerpo se ejecuta al menos una vez.

```js
let intento = 0;
do {
  intento++;
  console.log(`Intento ${intento}`);
} while (intento < 3);
```

## Los dos errores clásicos

**El bucle infinito.** Si la condición nunca se vuelve falsa, el bucle no termina y el programa se congela. Pasa cuando olvidas el paso (`i++`) o cuando la condición nunca puede cumplirse. Cada vuelta tiene que **acercarse** al final.

**Una vuelta de más (*off-by-one*).** Un array de 3 elementos tiene índices 0, 1 y 2. Si la condición es `i <= array.length`, el bucle llega a `i = 3` y lee algo que no existe. La condición correcta es `i < array.length`. Con `for…of` este error desaparece.

<Nota tipo="error">
  Si tu programa se queda colgado, sospecha de un bucle infinito. En este sitio, el laboratorio y los ejemplos se detienen solos al poco tiempo. En el navegador o en Node, el proceso se queda bloqueado hasta que lo cierres.
</Nota>

## ¿Cuál elijo?

| Quiero… | Usa |
|---|---|
| Recorrer los elementos de un array o las letras de un texto | `for…of` |
| Repetir un número fijo de veces, o necesito el índice | `for` |
| Repetir mientras algo sea cierto, sin saber cuántas veces | `while` |
| Lo mismo, pero ejecutando al menos una vez | `do…while` |
| Recorrer las claves de un objeto | `for…in` u `Object.keys()` |

Para transformar o filtrar arrays existen métodos como `map` y `filter`, que suelen ser todavía más claros que un bucle. Los vas a ver en la sección de Colecciones.

## Resumen

- `for (inicio; condición; paso)` repite mientras se cumpla la condición; el paso se ejecuta al final de cada vuelta.
- `for…of` recorre **valores** (arrays, textos); `for…in` recorre **claves** de objetos.
- `while` repite mientras una condición sea cierta; `do…while` da al menos una vuelta.
- Cada vuelta debe acercarse al final, o tendrás un **bucle infinito**.
- Para arrays, `i < array.length`, no `<=`. O mejor, `for…of`.
