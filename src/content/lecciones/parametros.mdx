## Argumentos que faltan o sobran

```js
function presentar(nombre, ciudad) {
  return `${nombre} vive en ${ciudad}`;
}

console.log(presentar("Ana", "Lima"));          // normal
console.log(presentar("Ana"));                  // falta uno: undefined
console.log(presentar("Ana", "Lima", "Perú"));  // sobra uno: se ignora
```

No hay error en ningún caso: los parámetros sin argumento valen `undefined` y los argumentos de más se descartan.

## Valores por defecto

Un `=` después del parámetro le da un valor para cuando llegue `undefined`:

```js
function saludar(nombre = "visitante", signo = "!") {
  return `Hola, ${nombre}${signo}`;
}

console.log(saludar());
console.log(saludar("Eva"));
console.log(saludar("Eva", "?"));
console.log(saludar(undefined, "?"));  // undefined usa el valor por defecto
console.log(saludar(null));            // null no: es un valor
```

El valor por defecto se calcula **en cada llamada**, y puede usar los parámetros anteriores: `function crear(ancho, alto = ancho)`.

## El parámetro rest

`...nombre` como último parámetro junta todos los argumentos restantes en un **array**:

```js
function sumarTodo(...numeros) {
  let total = 0;
  for (const n of numeros) total += n;
  return total;
}

console.log(sumarTodo(1, 2, 3, 4));
console.log(sumarTodo());

function etiquetar(etiqueta, ...items) {
  return items.map((i) => `${etiqueta}: ${i}`);
}
console.log(etiquetar("fruta", "pera", "uva"));
```

Es lo contrario del **spread** al llamar: `Math.max(...lista)` reparte un array en argumentos.

<Nota>
  En código antiguo verás `arguments`, un objeto con todos los argumentos que existe dentro de las funciones normales. Parece un array pero no lo es, y las flechas no lo tienen. El rest lo reemplaza con ventaja.
</Nota>

## Objetos de opciones

Cuando una función tiene muchos parámetros opcionales, el orden se vuelve un problema: `crearVentana(400, 300, true, false, "oscuro")` no se entiende. La solución moderna es recibir **un objeto** y desestructurarlo, como viste en *Desestructuración y spread*:

```js
function crearVentana({ ancho = 400, alto = 300, tema = "claro", modal = false } = {}) {
  return `${ancho}×${alto} · ${tema}${modal ? " · modal" : ""}`;
}

console.log(crearVentana({ tema: "oscuro", modal: true }));
console.log(crearVentana());
```

Cada opción tiene nombre, el orden no importa y las que no pasas toman su valor por defecto.

## El viejo arguments

Antes de que existiera el parámetro rest, cada función recibía un objeto **`arguments`** con todos los argumentos. Lo vas a ver en código antiguo:

```js
function sumar() {
  console.log(arguments.length, Array.isArray(arguments));
  return Array.from(arguments).reduce((a, b) => a + b, 0);
}
console.log(sumar(1, 2, 3));
```

Tiene sus mañas: parece un array, pero no lo es (no tiene `map` ni `reduce` hasta que lo conviertes), y **las funciones flecha no tienen el suyo**, así que dentro de una flecha `arguments` es el de la función que la rodea. Hoy `...args` hace lo mismo, con un array de verdad y un nombre que dice qué contiene.

## Cómo se pasan los argumentos

Pasar un argumento funciona como una **asignación**: el parámetro recibe una copia del valor. Con primitivos, una copia independiente; con objetos, una copia de la **referencia**, así que la función puede modificar el objeto original:

```js
function renombrar(usuario) {
  usuario.nombre = "Cambiado";   // modifica el objeto de afuera
}

function reemplazar(usuario) {
  usuario = { nombre: "Nuevo" }; // solo cambia la variable local
}

const ana = { nombre: "Ana" };
reemplazar(ana);
console.log(ana.nombre);  // Ana
renombrar(ana);
console.log(ana.nombre);  // Cambiado
```

Por eso es buena práctica que las funciones **no modifiquen** los objetos que reciben: si necesitan cambiar algo, que devuelvan uno nuevo.

## Resumen

- Los argumentos que faltan valen `undefined`; los que sobran se ignoran.
- `param = valor` da un valor por defecto, que se usa solo con `undefined`.
- `...resto`, siempre al final, junta los argumentos sobrantes en un array.
- Con muchas opciones, recibe un **objeto** y desestructúralo con valores por defecto.
- Los objetos se pasan por **referencia compartida**: la función puede modificarlos.
- `arguments` es la forma antigua de leer todos los argumentos: no es un array y las flechas no lo tienen. Usa `...args`.
