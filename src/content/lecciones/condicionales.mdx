## if

`if (condición) { … }` ejecuta el bloque solo si la condición es truthy:

```js
const saldo = 120;

if (saldo > 100) {
  console.log("Tienes saldo de sobra");
}
console.log("Esto se ejecuta siempre");
```

Si el bloque tiene una sola línea, puedes omitir las llaves: `if (saldo > 100) console.log("…");`. Muchos equipos prefieren ponerlas siempre, porque al agregar una segunda línea es fácil olvidarlas.

## else y else if

`else` da un camino para cuando la condición **no** se cumple. Con `else if` encadenas varias condiciones:

```js
const hora = 15;

if (hora < 12) {
  console.log("Buenos días");
} else if (hora < 20) {
  console.log("Buenas tardes");
} else {
  console.log("Buenas noches");
}
```

Como muestra el pizarrón, se ejecuta **solo el primer bloque** cuya condición se cumple. Por eso el orden importa: si la primera condición fuera `hora < 20`, nunca verías "Buenos días".

## Combinar condiciones

Usa `&&` y `||` dentro de la condición:

```js
const edad = 25;
const tieneEntrada = true;

if (edad >= 18 && tieneEntrada) {
  console.log("Puede pasar");
}

const dia = "domingo";
if (dia === "sábado" || dia === "domingo") {
  console.log("Fin de semana");
}
```

Para comprobar si un valor está en un rango, escribe las dos comparaciones: `edad >= 13 && edad <= 19`. La forma de las matemáticas, `13 <= edad <= 19`, **no** funciona en JavaScript: compara `true <= 19`.

## switch

Cuando comparas **un mismo valor** con varias opciones fijas, `switch` puede ser más claro que una cadena de `else if`:

```js
const fruta = "pera";

switch (fruta) {
  case "manzana":
    console.log("Roja o verde");
    break;
  case "pera":
  case "membrillo":
    console.log("Amarilla");
    break;
  default:
    console.log("No la conozco");
}
```

- Cada `case` compara con `===`.
- **`break`** sale del `switch`. Si lo olvidas, la ejecución sigue con el `case` siguiente.
- Varios `case` seguidos y vacíos **comparten** el mismo código, como `"pera"` y `"membrillo"`.
- `default` se ejecuta si ningún `case` coincide.

<Nota>
  Olvidar un `break` es el error clásico del `switch`: el código "cae" al siguiente caso sin avisar. Si tu `switch` hace algo raro, revisa primero los `break`.
</Nota>

## El ternario, para elegir un valor

Cuando solo necesitas **elegir un valor** entre dos, el operador ternario es más corto que un `if`:

```js
const stock = 0;
const mensaje = stock > 0 ? "Disponible" : "Agotado";
console.log(mensaje);
```

Úsalo para valores, no para ejecutar acciones distintas: para eso, `if`.

## Condiciones claras

Algunas costumbres que hacen las decisiones más fáciles de leer:

- **Ponle nombre a las condiciones complicadas**: `const puedeComprar = edad >= 18 && saldo >= precio;` y después `if (puedeComprar)`.
- **Evita la doble negación**: `if (!noEsValido)` cuesta leerlo; escribe `if (esValido)`.
- **Sal pronto**: dentro de una función, comprueba primero los casos que no sirven y termina con `return`. Así el caso normal no queda enterrado en varios niveles de llaves. Lo vas a practicar en la sección de Funciones.

## Resumen

- `if` ejecuta un bloque si la condición es truthy; `else` da el camino contrario.
- En una cadena `if / else if / else` se ejecuta **solo el primer bloque** que se cumple. El orden importa.
- Combina condiciones con `&&` y `||`; un rango se escribe `a >= x && a <= y`.
- `switch` compara un valor con varios `case` usando `===`; no olvides el `break`.
- El ternario elige **un valor**; `if` elige **qué código** ejecutar.
