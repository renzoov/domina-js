## Las partes de una URL

```js
const url = new URL("https://ana:clave@tienda.com:8080/productos/te?color=verde&pagina=2#opiniones");

console.log(url.protocol);  // https:
console.log(url.username, url.password);
console.log(url.hostname, url.port);
console.log(url.host);      // con el puerto
console.log(url.origin);    // protocolo + host
console.log(url.pathname);
console.log(url.search);
console.log(url.hash);
```

Las partes se pueden **cambiar**, y la URL se actualiza entera:

```js
const url = new URL("https://tienda.com/productos");
url.pathname = "/productos/té verde";
url.hash = "precio";
console.log(url.href);
```

Fíjate en que los caracteres especiales del camino se codificaron solos.

## Rutas relativas

El segundo argumento es la **base** contra la que se resuelve una ruta relativa, igual que hace el navegador con un enlace:

```js
const base = "https://tienda.com/es/productos/te";

console.log(new URL("cafe", base).href);        // hermano
console.log(new URL("../ayuda", base).href);    // sube un nivel
console.log(new URL("/carrito", base).href);    // desde la raíz
console.log(new URL("?pagina=2", base).href);   // solo cambia la búsqueda
```

## ¿Es una URL válida?

`new URL` lanza un `TypeError` si el texto no es una URL. Para comprobar sin `try/catch`:

```js
console.log(URL.canParse("https://ejemplo.com"));   // true
console.log(URL.canParse("no es una url"));         // false
console.log(URL.parse("tampoco"));                  // null, en lugar de lanzar
console.log(URL.parse("/perfil", "https://a.com")?.href);
```

## URLSearchParams

`url.searchParams` es un objeto para leer y escribir los parámetros de búsqueda, que se encarga de la codificación:

```js
const url = new URL("https://tienda.com/buscar?q=te&etiqueta=oferta&etiqueta=nuevo");
const p = url.searchParams;

console.log(p.get("q"), p.has("pagina"));
console.log(p.getAll("etiqueta"));    // un parámetro puede repetirse

p.set("q", "té & café");              // reemplaza
p.append("pagina", "2");              // agrega
p.delete("etiqueta");
console.log(url.search);

for (const [clave, valor] of p) console.log(clave, "=", valor);
```

También se puede usar sola, por ejemplo para armar el cuerpo de un formulario o leer los parámetros de la página actual:

```js
const params = new URLSearchParams({ nombre: "Ana López", edad: 31 });
console.log(params.toString());

const leidos = new URLSearchParams("?orden=precio&desc=1");
console.log(Object.fromEntries(leidos));
```

<Nota tipo="ojo">
  Los parámetros siempre son **textos**: `p.get("pagina")` devuelve `"2"`, no `2`. Conviértelos con `Number(…)` antes de hacer cuentas. Y `get` devuelve `null` si el parámetro no existe.
</Nota>

## Resumen

- `new URL(texto, base?)` separa una dirección en partes: `protocol`, `hostname`, `pathname`, `search`, `hash`…
- La base resuelve rutas relativas como un navegador.
- `URL.canParse` y `URL.parse` comprueban sin lanzar errores.
- `searchParams` lee y escribe parámetros (`get`, `getAll`, `set`, `append`, `delete`) y **codifica** por ti.
- Nunca armes URLs concatenando textos.
