## Las novedades

| Novedad | Qué hace | Se explica en |
|---|---|---|
| **Temporal** | Fechas, horas, zonas e instantes, inmutables y sin sorpresas | [Fechas: Date y Temporal](/biblioteca-estandar/fechas) |
| `using`, `await using`, `DisposableStack` | Liberar recursos automáticamente al salir del bloque | [Gestión explícita de recursos](/biblioteca-estandar/using) |
| `Iterator.zip` | Recorrer varios iteradores a la vez | [Iterator helpers](/iteradores/iterator-helpers) |
| *Chunking* (`chunks`, `windows`) | Partir un iterador en bloques o ventanas | [Iterator helpers](/iteradores/iterator-helpers) |
| `includes` y `join` en iteradores | Como en los arrays | [Iterator helpers](/iteradores/iterator-helpers) |
| `Atomics.pause` | Una pausa eficiente al esperar en memoria compartida | (tema avanzado de hilos) |

## En una mirada

```js
const salida = Temporal.ZonedDateTime.from("2026-12-24T22:00[America/Lima]");
const llegada = salida.add({ hours: 13 }).withTimeZone("Europe/Madrid");
console.log(llegada.toPlainDateTime().toString());

class Conexion {
  constructor(nombre) { this.nombre = nombre; console.log("abre", nombre); }
  [Symbol.dispose]() { console.log("cierra", this.nombre); }
}
{
  using db = new Conexion("principal");
  console.log("consultando…");
}

console.log(Iterator.from(["a", "b", "c"]).join(" · "));
```

## Resumen

- **Temporal** reemplaza a `Date`.
- `using` y `await using` liberan recursos solos; `DisposableStack` los agrupa.
- Más *iterator helpers*: `zip`, *chunking*, `includes` y `join`.
- `Atomics.pause` para la programación con hilos.
