## La función y su resultado

Fíjate en la diferencia entre el nombre de una función y el nombre seguido de paréntesis:

```js
function saludar() {
  return "¡Hola!";
}

console.log(typeof saludar);    // function: la función misma
console.log(saludar());         // ¡Hola!: lo que devuelve al ejecutarla

const otroNombre = saludar;     // la misma función, con otro nombre
console.log(otroNombre());
```

Los paréntesis **ejecutan**. Sin ellos, hablas de la función como un objeto más, sin ejecutarla. Esta distinción es la clave de todo el tema.

## Callbacks: pasar una función a otra

Un **callback** es una función que le pasas a otra para que **ella** la llame cuando corresponda:

```js
const precios = [10, 25, 8];

const conIva = precios.map((p) => p * 1.2);     // map llama al callback con cada precio
const caros = precios.filter((p) => p > 9);     // filter decide qué se queda

console.log(conIva);
console.log(caros);
```

Lo mismo con un temporizador o un evento: le das la función y el runtime la llamará más tarde.

```js
function avisar() {
  console.log("¡Tiempo!");
}

setTimeout(avisar, 1000);       // bien: pasas la función
// setTimeout(avisar(), 1000);  // mal: la ejecutas ahora y pasas undefined
```

## Funciones de orden superior

Una función que **recibe** o **devuelve** funciones se llama de **orden superior**. Puedes escribir las tuyas:

```js
function repetir(veces, accion) {
  for (let i = 1; i <= veces; i++) {
    accion(i);
  }
}

repetir(3, (n) => console.log(`Vuelta ${n}`));
```

Y una función que **devuelve** otra es una fábrica, como las que viste en *Closures*:

```js
const crearValidador = (minimo) => (texto) => texto.length >= minimo;

const claveSegura = crearValidador(8);
console.log(claveSegura("abc"));
console.log(claveSegura("unaclavelarga"));
```

## Funciones guardadas en estructuras

Como son valores, puedes guardarlas en objetos y arrays. Un objeto de funciones reemplaza a menudo un `switch` largo:

```js
const formatos = {
  mayus: (t) => t.toUpperCase(),
  minus: (t) => t.toLowerCase(),
  titulo: (t) => t[0].toUpperCase() + t.slice(1).toLowerCase(),
};

function formatear(texto, estilo) {
  const fn = formatos[estilo] ?? ((t) => t);
  return fn(texto);
}

console.log(formatear("hOLA mUNDO", "titulo"));
console.log(formatear("hola", "desconocido"));
```

<Nota tipo="consejo">
  Si un callback solo pasa su argumento a otra función, puedes pasar esa función directamente: `nombres.map((n) => mayus(n))` es lo mismo que `nombres.map(mayus)`. Pero ojo: `map` pasa tres argumentos (elemento, índice y array), y algunas funciones, como `parseInt`, usan el segundo.
</Nota>

## Resumen

- Las funciones son **valores**: se guardan, se pasan y se devuelven.
- `f` es la función; `f()` la **ejecuta**. Para pasarla, va sin paréntesis.
- Un **callback** es una función que otra función llama por ti.
- Las funciones de **orden superior** reciben o devuelven funciones.
- Un objeto de funciones es una alternativa clara a un `switch` largo.
