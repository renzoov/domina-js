## Las novedades

| Novedad | Qué hace | Se explica en |
|---|---|---|
| `String.prototype.replaceAll` | Reemplaza todas las apariciones de un texto | [Texto y template literals](/fundamentos/texto) |
| `Promise.any` y `AggregateError` | La primera promesa que se cumpla; si fallan todas, un error con todos los motivos | [Combinadores de promesas](/asincronia/combinadores) |
| `&&=`, `\|\|=`, `??=` | Asignar solo cuando hace falta | [Operadores](/fundamentos/operadores) |
| Separadores numéricos (`1_000_000`) | Números largos más legibles | [Números](/fundamentos/numeros) |
| `WeakRef` y `FinalizationRegistry` | Referencias débiles y avisos cuando se libera un objeto | [Memoria y recolector de basura](/como-se-ejecuta-js/memoria) |

## En una mirada

```js
const precios = { envio: 0, descuento: null };
precios.envio ||= 5;          // 0 es falsy: lo reemplaza
precios.descuento ??= 10;     // null: lo reemplaza
console.log(precios);

const presupuesto = 2_500_000;
console.log(presupuesto / 1_000);

console.log("2026-11-21".replaceAll("-", "/"));

try {
  await Promise.any([Promise.reject(new Error("A")), Promise.reject(new Error("B"))]);
} catch (e) {
  console.log(e.name, e.errors.length);
}
```

## Resumen

- `replaceAll` sin expresiones regulares.
- `Promise.any` y `AggregateError`.
- Asignaciones lógicas `&&=`, `||=` y `??=`.
- Separadores numéricos con guion bajo.
- `WeakRef` y `FinalizationRegistry`, para casos avanzados de memoria.
