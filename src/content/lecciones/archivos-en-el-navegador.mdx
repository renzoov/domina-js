## Elegir archivos

Un `<input type="file">` abre el diálogo del sistema. Con `multiple` se pueden elegir varios, y `accept` sugiere qué tipos mostrar (`image/*`, `.pdf,.csv`). Lo elegido queda en `input.files`, una lista de objetos **`File`**:

```js
document.body.innerHTML = `<input type="file" id="fotos" multiple accept="image/*">`;
const campo = document.querySelector("#fotos");

campo.addEventListener("change", () => {
  for (const archivo of campo.files) {
    console.log(archivo.name, archivo.type, `${archivo.size} bytes`);
  }
});

// Simula que el usuario eligió dos archivos (en tu página los elige con el diálogo)
const elegidos = new DataTransfer();
elegidos.items.add(new File(["abc"], "playa.jpg", { type: "image/jpeg" }));
elegidos.items.add(new File(["abcdef"], "perro.png", { type: "image/png" }));
campo.files = elegidos.files;
campo.dispatchEvent(new Event("change"));
```

Cada `File` trae su nombre, su tipo MIME, su tamaño en bytes y la fecha de modificación (`lastModified`). No trae la ruta en el disco: esa nunca se expone.

<Nota>
  `accept` solo filtra el diálogo: la persona puede cambiar el filtro y elegir cualquier cosa. Comprueba el tipo y el tamaño en tu código, y **otra vez en el servidor**.
</Nota>

## Leer el contenido

Un `File` es un `Blob` con nombre, y los dos tienen métodos que devuelven promesas:

- **`text()`**: el contenido como texto.
- **`arrayBuffer()`** o **`bytes()`**: los bytes crudos, para trabajarlos con arrays tipados (lo viste en *Datos binarios*).
- **`stream()`**: de a trozos, para archivos enormes.

```js
const archivo = new File(["nombre,edad\nAna,31\nLuis,28"], "personas.csv", { type: "text/csv" });

const texto = await archivo.text();
const filas = texto.split("\n").slice(1).map((linea) => linea.split(","));
console.log(filas);
```

En código más antiguo verás **`FileReader`**, que hace lo mismo con eventos en lugar de promesas. Su única ventaja hoy es `readAsDataURL`, que convierte el archivo en una URL `data:` con el contenido dentro:

```js
const archivo = new File(["hola"], "saludo.txt", { type: "text/plain" });

const url = await new Promise((resolver, rechazar) => {
  const lector = new FileReader();
  lector.onload = () => resolver(lector.result);
  lector.onerror = () => rechazar(lector.error);
  lector.readAsDataURL(archivo);
});
console.log(url);
```

## Mostrar una imagen antes de subirla

Para mostrar la foto que alguien acaba de elegir no hace falta leerla. **`URL.createObjectURL(archivo)`** crea una dirección temporal que apunta al archivo en memoria, y sirve en un `<img>`, un `<video>` o un enlace:

```js
document.body.innerHTML = `<img id="vista" alt="Vista previa de la foto" width="120">`;
const vista = document.querySelector("#vista");

const foto = new File(["…"], "perfil.png", { type: "image/png" });
const direccion = URL.createObjectURL(foto);
vista.src = direccion;
console.log(direccion.startsWith("blob:"));

// Cuando ya no la necesites, libérala: si no, el archivo se queda en memoria
vista.addEventListener("load", () => URL.revokeObjectURL(direccion), { once: true });
```

## Crear un archivo y descargarlo

Al revés también funciona: armas el contenido en un **`Blob`**, le creas una dirección y la descargas con un enlace que tiene el atributo `download`:

```js
const datos = [{ nombre: "Ana", puntos: 31 }, { nombre: "Luis", puntos: 28 }];
const csv = ["nombre,puntos", ...datos.map((d) => `${d.nombre},${d.puntos}`)].join("\n");

const blob = new Blob([csv], { type: "text/csv" });
console.log(blob.size, "bytes,", blob.type);

const enlace = document.createElement("a");
enlace.href = URL.createObjectURL(blob);
enlace.download = "puntos.csv";   // el nombre con que se guarda
// enlace.click();                // en tu página, esto inicia la descarga
URL.revokeObjectURL(enlace.href);
```

Así funciona, por ejemplo, el botón «Descargar copia» de *Tu progreso*, en el temario de este sitio.

## Subir archivos

Un archivo se sube como cualquier otro campo de un formulario, dentro de un `FormData` (lo viste en *Formularios y validación*):

```js
const datos = new FormData();
datos.append("titulo", "Vacaciones");
datos.append("foto", campo.files[0]);
await fetch("/api/fotos", { method: "POST", body: datos });
```

`fetch` todavía no informa **cuánto se subió**. Para una barra de progreso hay que usar el viejo `XMLHttpRequest`, que tiene el evento `progress` en `xhr.upload`:

```js
const xhr = new XMLHttpRequest();
xhr.upload.addEventListener("progress", (e) => {
  if (e.lengthComputable) barra.value = e.loaded / e.total;   // de 0 a 1
});
xhr.addEventListener("load", () => console.log("subido:", xhr.status));
xhr.open("POST", "/api/fotos");
xhr.send(datos);
```

## Abrir y guardar como una aplicación

La **File System Access API** va un paso más allá: `showOpenFilePicker()` y `showSaveFilePicker()` abren los diálogos del sistema y devuelven un "manejador" con el que tu página puede **volver a guardar en el mismo archivo**, como un editor de verdad. Por ahora solo existe en Chrome, Edge y otros navegadores basados en Chromium, así que úsala comprobando primero que exista (`if ("showSaveFilePicker" in window)`) y con el `<input>` y la descarga como plan B.

## Resumen

- `<input type="file" multiple accept>` deja elegir archivos; quedan en `input.files` como objetos `File`.
- Léelos con `text()`, `arrayBuffer()`, `bytes()` o `stream()`; `FileReader` es la forma antigua.
- `URL.createObjectURL` da una dirección temporal para mostrar o descargar; libérala con `revokeObjectURL`.
- Crea archivos con `new Blob([contenido], { type })` y descárgalos con `<a download>`.
- Súbelos dentro de un `FormData`; para ver el progreso, `XMLHttpRequest` con `xhr.upload`.
- El tipo y el tamaño se comprueban siempre en el servidor.
