## Las novedades

| Novedad | Qué hace | Se explica en |
|---|---|---|
| `Object.groupBy` y `Map.groupBy` | Agrupar una lista según un criterio | [Agrupar datos](/colecciones/agrupar) |
| `Promise.withResolvers` | Una promesa con su `resolve` y `reject` por separado | [Combinadores de promesas](/asincronia/combinadores) |
| Bandera `v` en expresiones regulares | Operaciones de conjuntos y Unicode mejorado | [Expresiones regulares](/biblioteca-estandar/expresiones-regulares) |
| `ArrayBuffer` redimensionable y `transfer` | Buffers que crecen y se traspasan sin copiar | [Datos binarios](/colecciones/datos-binarios) |
| `isWellFormed` y `toWellFormed` | Detectar y reparar texto con sustitutos sueltos | [Unicode y emojis](/biblioteca-estandar/unicode) |
| `Atomics.waitAsync` | Esperar de forma asíncrona en memoria compartida | (tema avanzado de hilos) |

## En una mirada

```js
const pedidos = [
  { cliente: "Ana", estado: "enviado" },
  { cliente: "Luis", estado: "pendiente" },
  { cliente: "Eva", estado: "pendiente" },
];
const porEstado = Object.groupBy(pedidos, (p) => p.estado);
console.log(Object.keys(porEstado), porEstado.pendiente.length);

const buffer = new ArrayBuffer(4, { maxByteLength: 16 });
buffer.resize(12);
console.log(buffer.byteLength);

console.log("café\uD800".isWellFormed(), "café\uD800".toWellFormed());
```

## Resumen

- `Object.groupBy` y `Map.groupBy`.
- `Promise.withResolvers`.
- Bandera `v` en las expresiones regulares.
- `ArrayBuffer` redimensionable y `transfer`.
- `isWellFormed` y `toWellFormed` para el texto.
