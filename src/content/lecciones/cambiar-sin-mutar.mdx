## El problema

```js
const ranking = [70, 95, 80];

function top(lista) {
  return lista.sort((a, b) => b - a)[0];
}

console.log(top(ranking));
console.log(ranking);  // ¡reordenado! top modificó los datos de quien la llamó
```

`top` solo quería leer, pero `sort` reordenó el array original. Cualquier otra parte del programa que usara `ranking` ve ahora otro orden.

## Cuatro métodos nuevos (ES2023)

| Modifica | Devuelve una copia |
|---|---|
| `lista.sort(fn)` | `lista.toSorted(fn)` |
| `lista.reverse()` | `lista.toReversed()` |
| `lista.splice(i, n, ...nuevos)` | `lista.toSpliced(i, n, ...nuevos)` |
| `lista[i] = valor` | `lista.with(i, valor)` |

```js
const letras = ["c", "a", "d", "b"];

console.log(letras.toSorted());
console.log(letras.toReversed());
console.log(letras.toSpliced(1, 2, "X"));  // quita 2 desde el índice 1 y pone "X"
console.log(letras.with(0, "Z"));
console.log(letras.with(-1, "Ω"));         // acepta índices negativos
console.log(letras);                        // intacto
```

## Listas de objetos

Copiar el array no copia los objetos que tiene adentro: es una copia **superficial**, como viste en *Copias*. Para "cambiar" un objeto de la lista sin mutarlo, crea uno nuevo para ese lugar:

```js
const carrito = [
  { producto: "té", cantidad: 1 },
  { producto: "pan", cantidad: 2 },
];

// Cambiar la cantidad del pan, sin tocar carrito ni sus objetos
const actualizado = carrito.with(1, { ...carrito[1], cantidad: 3 });

console.log(actualizado[1].cantidad, carrito[1].cantidad);
console.log(actualizado[0] === carrito[0]);  // el té se comparte: no cambió
```

Las operaciones habituales con este estilo:

```js
const lista = [{ id: 1, hecha: false }, { id: 2, hecha: false }];

const agregada = [...lista, { id: 3, hecha: false }];             // agregar
const sinLaDos = lista.filter((t) => t.id !== 2);                  // quitar
const marcada = lista.map((t) => (t.id === 1 ? { ...t, hecha: true } : t)); // cambiar uno

console.log(agregada.length, sinLaDos.length, marcada[0].hecha, lista[0].hecha);
```

<Nota>
  React, Vue, Redux y muchas otras librerías detectan los cambios comparando **referencias**: si mutas un array, sigue siendo "el mismo" y no se enteran. Por eso en esos entornos se trabaja siempre así.
</Nota>

## Resumen

- `sort`, `reverse` y `splice` **modifican** el array; también `lista[i] = x`.
- ES2023 agregó `toSorted`, `toReversed`, `toSpliced` y `with`, que devuelven **copias**.
- Las copias son superficiales: para cambiar un objeto de la lista, crea uno nuevo con spread.
- Agregar con spread, quitar con `filter`, cambiar con `map` o `with`.
