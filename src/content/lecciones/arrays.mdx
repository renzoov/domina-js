## Crear y leer

Un array se escribe entre corchetes. Cada elemento tiene un **índice**, que empieza en 0:

```js
const frutas = ["manzana", "pera", "uva"];

console.log(frutas[0]);        // manzana
console.log(frutas.length);    // 3
console.log(frutas[frutas.length - 1]);  // el último
console.log(frutas.at(-1));    // el último, con at (ES2022)
console.log(frutas[10]);       // undefined: no existe
```

Un array puede guardar valores de cualquier tipo, mezclados, incluso otros arrays. Pero en la práctica, una lista suele tener elementos **del mismo tipo**, y así es más fácil trabajar con ella.

## Cambiar elementos

```js
const tareas = ["leer", "escribir"];

tareas[1] = "practicar";    // reemplaza
tareas.push("descansar");   // agrega al final
tareas.unshift("despertar"); // agrega al principio
console.log(tareas);

const ultima = tareas.pop();     // quita del final y la devuelve
const primera = tareas.shift();  // quita del principio
console.log(ultima, primera, tareas);
```

Igual que con los objetos, `const` no impide cambiar el contenido: solo reasignar la variable.

## Buscar

```js
const colores = ["rojo", "verde", "azul", "verde"];

console.log(colores.includes("azul"));     // ¿está?
console.log(colores.indexOf("verde"));     // primer índice
console.log(colores.lastIndexOf("verde")); // último índice
console.log(colores.indexOf("negro"));     // -1: no está
```

Para buscar con una condición, como "el primer número mayor que 10", están `find` y `findIndex`, en el próximo tema.

## Recorrer

```js
const notas = [8, 6, 9];

for (const nota of notas) {
  console.log(nota);
}

for (const [i, nota] of notas.entries()) {
  console.log(`nota ${i + 1}: ${nota}`);
}
```

## Crear arrays de otras formas

```js
console.log(Array.from("hola"));                     // de un iterable
console.log(Array.from({ length: 3 }, (_, i) => i * 10)); // con una función
console.log(Array.of(7));                            // un array con el 7
console.log(new Array(3).fill(0));                   // tres ceros
console.log([..."abc", ...[1, 2]]);                  // con spread
```

<Nota tipo="ojo">
  Asignar más allá del final crea **huecos**: `lista[10] = "x"` en un array de 3 elementos deja los índices 3 a 9 vacíos y `length` en 11. Los métodos tratan los huecos de forma distinta entre sí. Evítalos: usa `push`.
</Nota>

## Resumen

- Un array es una lista ordenada; los índices van de `0` a `length - 1`.
- `at(-1)` lee desde el final (ES2022).
- `push`/`pop` trabajan al final; `unshift`/`shift`, al principio.
- `includes` e `indexOf` buscan valores; `for...of` recorre.
- `Array.from`, `Array.of`, `fill` y spread crean arrays.
- `typeof []` es `"object"`: usa `Array.isArray`.
