## Las novedades

| Novedad | Qué hace | Se explica en |
|---|---|---|
| `findLast` y `findLastIndex` | Buscar desde el final | [Métodos de array](/colecciones/metodos-de-array) |
| `toSorted`, `toReversed`, `toSpliced`, `with` | Copias con cambios, sin mutar | [Cambiar sin mutar](/colecciones/cambiar-sin-mutar) |
| Symbols como claves de `WeakMap` y `WeakSet` | Claves débiles que no son objetos | [WeakMap y WeakSet](/colecciones/weakmap-y-weakset) |
| Gramática *hashbang* (`#!/usr/bin/env node`) | La primera línea de un script ejecutable es válida | [Node.js hoy](/servidor/node-hoy) |

## En una mirada

```js
const notas = [7, 9, 4, 8];

console.log(notas.toSorted((a, b) => b - a), notas);   // el original no cambia
console.log(notas.toReversed().at(0));
console.log(notas.toSpliced(1, 2, 10));
console.log(notas.with(-1, 6));
console.log(notas.findLast((n) => n < 8), notas.findLastIndex((n) => n < 8));
```

## Resumen

- `findLast` y `findLastIndex`.
- `toSorted`, `toReversed`, `toSpliced` y `with`: cambiar sin mutar.
- Symbols no registrados como claves débiles.
- Hashbang al principio de los scripts.
