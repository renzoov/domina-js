## Canvas

Un `<canvas>` es una superficie de píxeles. Le pides un **contexto** de dibujo y le das órdenes:

```js
document.body.innerHTML = `<canvas id="lienzo" width="300" height="120"></canvas>`;
const ctx = document.querySelector("#lienzo").getContext("2d");

ctx.fillStyle = "#1b2a23";
ctx.fillRect(0, 0, 300, 120);              // fondo

ctx.fillStyle = "#f7df1e";
ctx.fillRect(20, 20, 80, 80);              // un cuadrado

ctx.beginPath();                           // un círculo, con un trazado
ctx.arc(170, 60, 40, 0, Math.PI * 2);
ctx.strokeStyle = "#8fd0f7";
ctx.lineWidth = 4;
ctx.stroke();

ctx.fillStyle = "#f2a7b8";
ctx.font = "bold 20px system-ui";
ctx.fillText("JS", 240, 68);

console.log("dibujado");
```

Lo que pintas son solo píxeles: el canvas no recuerda que ahí hay "un círculo". Para moverlo, borras (`clearRect`) y repintas todo.

## Animar un canvas

Las animaciones repintan en cada cuadro con `requestAnimationFrame`. La función recibe la hora del cuadro, y conviene mover las cosas según el **tiempo** que pasó, no según la cantidad de cuadros: así la animación dura lo mismo en una pantalla de 60 cuadros por segundo, en una de 120 o en un teléfono que ahorra batería:

```js
document.body.innerHTML = `<canvas id="lienzo" width="300" height="80"></canvas>`;
const ctx = document.querySelector("#lienzo").getContext("2d");
const VELOCIDAD = 0.26;   // píxeles por milisegundo
let inicio = null;

function cuadro(ahora) {
  inicio ??= ahora;
  const x = Math.min(240, (ahora - inicio) * VELOCIDAD);   // dónde va, según el tiempo
  ctx.clearRect(0, 0, 300, 80);
  ctx.fillStyle = "#c4ec8c";
  ctx.beginPath();
  ctx.arc(20 + x, 40, 16, 0, Math.PI * 2);
  ctx.fill();
  if (x < 240) requestAnimationFrame(cuadro);
  else console.log("llegó");
}
requestAnimationFrame(cuadro);
```

En pantallas de alta densidad, para que no se vea borroso, el tamaño interno del canvas tiene que multiplicarse por `devicePixelRatio`, y después escalar el contexto con `ctx.scale(dpr, dpr)`.

## Transformaciones

En lugar de calcular cada coordenada, puedes **mover, girar y escalar el sistema de coordenadas** y dibujar siempre alrededor del `(0, 0)`. `save()` guarda el estado del contexto (las transformaciones, los colores, el grosor) y `restore()` lo recupera:

```js
document.body.innerHTML = `<canvas id="lienzo" width="300" height="150"></canvas>`;
const ctx = document.querySelector("#lienzo").getContext("2d");

function aspa(color) {
  ctx.fillStyle = color;
  ctx.fillRect(-40, -8, 80, 16);   // siempre alrededor del (0, 0)
}

ctx.save();
ctx.translate(80, 75);              // el (0, 0) pasa al centro del primer dibujo
aspa("#f7df1e");
ctx.rotate(Math.PI / 2);            // gira 90° alrededor del nuevo origen
aspa("#f7df1e");
ctx.restore();                      // vuelve a como estaba antes del save()

ctx.translate(220, 75);
ctx.rotate(Math.PI / 4);
aspa("#8fd0f7");
ctx.rotate(Math.PI / 2);
aspa("#8fd0f7");
console.log(ctx.getTransform().e, ctx.getTransform().f);   // dónde quedó el origen
```

`ctx.scale(x, y)` agranda o achica, y se combina con las otras. Es lo mismo que usaste para el `devicePixelRatio`.

## Imágenes y píxeles

`ctx.drawImage(imagen, x, y, ancho, alto)` pinta una imagen, un video (el cuadro actual) u otro canvas. Y con **`getImageData`** obtienes los píxeles mismos: un array con cuatro números por píxel (rojo, verde, azul y transparencia, de 0 a 255) que puedes cambiar y volver a pintar con `putImageData`. Así funcionan los filtros de fotos:

```js
document.body.innerHTML = `<canvas id="lienzo" width="200" height="100"></canvas>`;
const ctx = document.querySelector("#lienzo").getContext("2d", { willReadFrequently: true });
ctx.fillStyle = "#f7df1e";
ctx.fillRect(0, 0, 100, 100);
ctx.fillStyle = "#8fd0f7";
ctx.fillRect(100, 0, 100, 100);

const imagen = ctx.getImageData(0, 0, 200, 100);
const p = imagen.data;   // [r, g, b, a, r, g, b, a, …]
console.log(p.length, p[0], p[1], p[2], p[3]);

for (let i = 0; i < p.length; i += 4) {   // a escala de grises
  const gris = Math.round(0.299 * p[i] + 0.587 * p[i + 1] + 0.114 * p[i + 2]);
  p[i] = p[i + 1] = p[i + 2] = gris;
}
ctx.putImageData(imagen, 0, 0);
console.log(ctx.getImageData(150, 50, 1, 1).data.join(","));
```

<Nota>
  Si pintas una imagen de **otro sitio** sin permiso, el canvas queda "contaminado" y `getImageData` lanza un `SecurityError`: así ninguna página puede leer imágenes ajenas a través de un canvas. El otro sitio tiene que permitirlo con CORS, y la imagen se carga con `img.crossOrigin = "anonymous"`.
</Nota>

## Exportar el dibujo

Un canvas se convierte en un archivo de imagen con **`toBlob`**, y se descarga como cualquier `Blob` (lo viste en *Archivos*):

```js
lienzo.toBlob((blob) => {
  const enlace = document.createElement("a");
  enlace.href = URL.createObjectURL(blob);
  enlace.download = "dibujo.png";
  enlace.click();
  URL.revokeObjectURL(enlace.href);
}, "image/png");   // también "image/jpeg" o "image/webp", con la calidad como tercer argumento
```

## SVG

En SVG, cada forma es un **elemento**, con atributos, estilos de CSS y eventos. Se crean con `createElementNS`, porque pertenecen al espacio de nombres de SVG:

```js
const SVG = "http://www.w3.org/2000/svg";
const svg = document.createElementNS(SVG, "svg");
svg.setAttribute("viewBox", "0 0 200 100");
svg.setAttribute("width", "300");

const circulo = document.createElementNS(SVG, "circle");
circulo.setAttribute("cx", 50);
circulo.setAttribute("cy", 50);
circulo.setAttribute("r", 30);
circulo.setAttribute("fill", "#f7df1e");
circulo.addEventListener("click", () => circulo.setAttribute("fill", "#f2a7b8"));
svg.append(circulo);

document.body.append(svg);
circulo.dispatchEvent(new MouseEvent("click"));   // simula un clic
console.log(circulo.getAttribute("fill"));
```

El `viewBox` define un sistema de coordenadas propio: el dibujo se escala al tamaño que le des, siempre nítido. Para dibujos fijos, como íconos, lo habitual es escribir el SVG directamente en el HTML y cambiar algún atributo o clase desde JavaScript.

Un SVG también se exporta: `new XMLSerializer().serializeToString(svg)` lo convierte en texto, que guardas en un `Blob` de tipo `"image/svg+xml"`.

## Gráficos de datos

Un gráfico de barras no es más que rectángulos con un alto proporcional a cada valor. Con SVG, cada barra es un elemento: puede llevar su `<title>` (el lector de pantalla y el mouse lo muestran) y reaccionar a eventos:

```js
const datos = [["Ene", 30], ["Feb", 45], ["Mar", 20]];
const SVG = "http://www.w3.org/2000/svg";
const svg = document.createElementNS(SVG, "svg");
svg.setAttribute("viewBox", "0 0 150 60");
svg.setAttribute("width", "300");
svg.setAttribute("role", "img");
svg.setAttribute("aria-label", "Ventas por mes: enero 30, febrero 45, marzo 20");

const maximo = Math.max(...datos.map(([, valor]) => valor));
datos.forEach(([mes, valor], i) => {
  const alto = (valor / maximo) * 50;
  const barra = document.createElementNS(SVG, "rect");
  for (const [k, v] of Object.entries({ x: 10 + i * 45, y: 55 - alto, width: 30, height: alto, fill: "#f7df1e" })) {
    barra.setAttribute(k, v);
  }
  const titulo = document.createElementNS(SVG, "title");
  titulo.textContent = `${mes}: ${valor}`;
  barra.append(titulo);
  svg.append(barra);
});

document.body.append(svg);
console.log(svg.querySelectorAll("rect").length, "barras");
```

Para gráficos con ejes, escalas, animaciones y leyendas, hay librerías que hacen el trabajo pesado: D3 te da las piezas para armarlos en SVG, y Chart.js los dibuja en un canvas con poca configuración.

## ¿Cuál uso?

| <span class="sr-only">Aspecto</span> | Canvas | SVG |
|---|---|---|
| Qué es | Píxeles | Elementos del DOM |
| Escala | Se pixela (hay que ajustarlo) | Siempre nítido |
| Muchos objetos (miles) | Muy rápido | Se vuelve pesado |
| Eventos por objeto | Hay que calcularlos a mano | Gratis, como en HTML |
| Accesibilidad | Hay que agregarla aparte | Con `<title>` y atributos ARIA |
| Ideal para | Juegos, partículas, imágenes, visualizaciones enormes | Íconos, gráficos interactivos, diagramas, logos |

<Nota>
  Para 3D y efectos muy pesados, el canvas tiene otros contextos: **WebGL** y su sucesor, **WebGPU**, que usan la tarjeta gráfica. Casi siempre se usan a través de una librería como Three.js.
</Nota>

## Resumen

- **Canvas**: un lienzo de píxeles; dibujas con un contexto (`getContext("2d")`) y no guarda objetos.
- Para animar un canvas, repinta en cada `requestAnimationFrame`.
- **SVG**: formas que son elementos, creadas con `createElementNS`; escalan sin perder calidad.
- `save`/`restore`, `translate`, `rotate` y `scale` mueven el sistema de coordenadas.
- `getImageData` y `putImageData` leen y cambian píxeles; `toBlob` exporta el dibujo como imagen.
- Canvas para muchísimos objetos o píxeles; SVG para gráficos interactivos, íconos y diagramas.
