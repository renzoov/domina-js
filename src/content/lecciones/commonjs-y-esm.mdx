## CommonJS

```js
// saludos.cjs
const prefijo = "Hola";

function saludar(nombre) {
  return `${prefijo}, ${nombre}`;
}

module.exports = { saludar };   // lo que se exporta es un objeto
```

```js
// main.cjs
const { saludar } = require("./saludos.cjs");
const fs = require("node:fs");

console.log(saludar("Ana"));
console.log(__dirname);   // la carpeta de este archivo
```

## Las diferencias

| | CommonJS | ES Modules |
|---|---|---|
| Sintaxis | `require()` y `module.exports` | `import` y `export` |
| Carga | **Síncrona**, en el momento del `require` | Se analiza antes de ejecutar; admite `await` de nivel superior |
| `require`/`import` | En cualquier lugar, incluso dentro de un `if` | `import` solo en el nivel superior; `import()` en cualquier lugar |
| Lo exportado | Un objeto con **copias** de los valores | **Enlaces vivos** a las variables |
| Modo estricto | Solo si lo pides | Siempre |
| Datos del archivo | `__dirname`, `__filename` | `import.meta.dirname`, `import.meta.filename` |
| En el navegador | No | Sí |

## Cómo decide Node.js

Para cada archivo:

1. **`.mjs`** → siempre ESM. **`.cjs`** → siempre CommonJS.
2. **`.js`** → mira el `package.json` más cercano: con `"type": "module"`, ESM; si no, CommonJS.

```json
{
  "name": "mi-proyecto",
  "type": "module"
}
```

Para proyectos nuevos, la recomendación es clara: `"type": "module"` y ESM en todas partes.

## Convivir

**De ESM a CommonJS** funciona sin problemas: puedes importar paquetes CommonJS. Su `module.exports` llega como exportación por defecto, y Node.js intenta detectar también las exportaciones con nombre:

```js
// main.mjs
import express from "express";          // un paquete CommonJS
import { readFile } from "node:fs/promises";
```

**De CommonJS a ESM** fue durante años el lado difícil: `require` es síncrono y ESM puede no serlo, así que había que usar el `import()` dinámico. Desde **Node 22** (y 20.19) existe **`require(esm)`**: puedes hacer `require` de un módulo ESM, siempre que no use `await` de nivel superior.

```js
// legado.cjs
const { formatear } = require("./util.mjs");   // funciona en Node 22+
```

<Nota tipo="consejo">
  Si publicas una librería, el campo `"exports"` del `package.json` te deja ofrecer las dos versiones a la vez: `{ "exports": { "import": "./dist/index.js", "require": "./dist/index.cjs" } }`. Cada usuario recibe la que su proyecto necesita.
</Nota>

## Resumen

- CommonJS es el sistema original de Node.js: `require()` y `module.exports`, carga síncrona.
- ESM es el estándar: `import`/`export`, enlaces vivos, modo estricto, también en el navegador.
- `.mjs` y `.cjs` deciden solos; los `.js` siguen el `"type"` del `package.json`.
- ESM puede importar CommonJS; desde Node 22, CommonJS puede hacer `require` de ESM sin `await` de nivel superior.
- En ESM no existen `require`, `module` ni `__dirname`: usa `import` e `import.meta`.
