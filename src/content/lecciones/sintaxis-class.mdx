## Una clase y sus instancias

```js
class Producto {
  constructor(nombre, precio) {
    this.nombre = nombre;
    this.precio = precio;
  }

  conIva() {
    return this.precio * 1.21;
  }

  describir() {
    return `${this.nombre}: ${this.precio}`;
  }
}

const mate = new Producto("Mate", 100);
const termo = new Producto("Termo", 250);

console.log(mate.describir());
console.log(termo.conIva());
console.log(mate);
```

- El **constructor** se ejecuta en cada `new`, con los argumentos que pases. Ahí guardas los datos en `this`, que es el objeto nuevo.
- Los **métodos** se escriben sin `function` ni comas entre ellos.
- Cada objeto creado con `new` es una **instancia** de la clase.

## Qué es una clase por debajo

Una clase no es un tipo nuevo de cosa: es una **función** con un **prototipo**. Los métodos no se copian en cada instancia, viven una sola vez en `Clase.prototype`, como viste en *Prototipos*:

```js
class Saludo {
  hola() { return "hola"; }
}

const s = new Saludo();
console.log(typeof Saludo);
console.log(Object.getPrototypeOf(s) === Saludo.prototype);
console.log(Object.hasOwn(s, "hola"));  // false: lo hereda
```

`new` hace cuatro cosas: crea un objeto vacío, lo enlaza a `Clase.prototype`, ejecuta el constructor con `this` apuntando a él y lo devuelve.

## Getters y setters

Un **getter** se lee como una propiedad, pero se calcula en cada lectura. Un **setter** se ejecuta al asignar, y sirve para validar:

```js
class Temperatura {
  constructor(celsius) {
    this.celsius = celsius;
  }

  get fahrenheit() {
    return this.celsius * 9 / 5 + 32;
  }

  set fahrenheit(valor) {
    this.celsius = (valor - 32) * 5 / 9;
  }
}

const t = new Temperatura(25);
console.log(t.fahrenheit);   // sin paréntesis
t.fahrenheit = 212;
console.log(t.celsius);
```

## Métodos estáticos

Un método `static` es de la **clase**, no de las instancias. Se usa para utilidades y para "fábricas" que crean instancias de formas especiales:

```js
class Color {
  constructor(r, g, b) {
    Object.assign(this, { r, g, b });
  }

  static desdeHex(hex) {
    const n = parseInt(hex.slice(1), 16);
    return new Color(n >> 16, (n >> 8) & 255, n & 255);
  }
}

console.log(Color.desdeHex("#F7DF1E"));
```

Ya conoces varios: `Array.from`, `Object.keys`, `Number.isInteger`.

<Nota tipo="ojo">
  Dos diferencias con las funciones normales: las clases **no se elevan** (están en la zona muerta temporal hasta su línea) y su código corre siempre en **modo estricto**.
</Nota>

## Resumen

- `class Nombre { constructor() {…} metodo() {…} }` define un molde; `new Nombre()` crea instancias.
- El **constructor** prepara cada instancia guardando datos en `this`.
- Los **métodos** viven en el prototipo y se comparten.
- **Getters** y **setters** se usan como propiedades, pero ejecutan código.
- Los métodos **static** son de la clase: `Clase.metodo()`.
- Una clase es una función: no se eleva, corre en modo estricto y exige `new`.
