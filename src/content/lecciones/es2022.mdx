## En una mirada

```js
class Contador {
  static #instancias = 0;
  #valor = 0;
  static { console.log("clase lista"); }
  constructor() { Contador.#instancias++; }
  sumar() { return ++this.#valor; }
  static cuantos() { return Contador.#instancias; }
}

const c = new Contador();
c.sumar();
console.log(c.sumar(), Contador.cuantos());

console.log("JavaScript".at(-1), [10, 20, 30].at(-2));

const m = /(?<anio>\d{4})/d.exec("año 2026");
console.log(m.indices.groups.anio);
```

## Resumen

- Clases completas: campos públicos y privados, métodos privados, bloques `static`, `#x in obj`.
- `await` de nivel superior en módulos.
- `at()` para leer desde el final; `Object.hasOwn`; `cause` en los errores.
- Bandera `d` para las posiciones de los grupos.
