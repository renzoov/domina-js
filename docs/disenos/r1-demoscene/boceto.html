LA PILA DE LLAMADAS

Lección 2 de 7 · 9 min · 4 ejercicios

JavaScript ejecuta tu código en un solo hilo: hace una cosa a la vez, en orden. Para no perderse cuando una función llama a otra, el motor lleva una lista de pendientes llamada pila de llamadas (call stack). La última función que entra es la primera que sale, como una pila de platos.

Avanza con «Siguiente» y mira cómo cada llamada se apila sobre la anterior.

VISUALIZADOR // PILAPASO 3 DE 8
1function saludar(nombre) {
2 return `Hola, ${nombre}!`;
3}
4
5function mostrar() {
6 const msg = saludar("Mundo");
7 console.log(msg);
8}
9
10mostrar();
11
PILACIMA ▲
saludar()PROF 2
mostrar()PROF 1
CONSOLA
(vacía)
saludar() se apila encima de mostrar(). El motor suspende mostrar() y ejecuta saludar().
