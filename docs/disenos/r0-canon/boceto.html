La pila de llamadas

⏱ 8 min· 4 ejercicios· Con visualizador

JavaScript tiene un solo hilo: hace una cosa a la vez. Para saber qué función se está ejecutando y a dónde volver cuando termina, el motor usa una estructura llamada pila de llamadas (call stack). Cada vez que llamas a una función, entra a la pila; cuando hace return, sale.
