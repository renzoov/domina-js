La pila de llamadas

8 min de lectura2 visualizadores4 ejercicios

JavaScript tiene un solo hilo: hace una cosa a la vez. Para saber en qué función está y adónde volver cuando termine, el motor usa una pila de llamadas (call stack). Cada llamada pone un marco encima; cada return lo quita. El último en entrar es el primero en salir.
