La pila de llamadas

JavaScript tiene un solo hilo: hace una cosa a la vez. Para saber qué función se está ejecutando y a dónde volver cuando termina, el motor usa una pila de llamadas (call stack). Cada llamada se apila encima de la anterior; al terminar, sale, y el motor continúa con la que quedó debajo.

Paso 3 de 8
