LECCIÓN 4.2·Cómo se ejecuta JS por dentro

La pila de llamadas

JavaScript tiene un solo hilo: hace una cosa a la vez. Para no perderse, el motor anota cada función que está ejecutando en una pila de llamadas (call stack): la última que entra es la primera que sale, como una pila de platos.

Sigue el ejemplo paso a paso: cada llamada se apila encima de la anterior, y cada return la retira.
