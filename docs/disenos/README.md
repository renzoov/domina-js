# Direcciones de diseño exploradas

Archivo de todas las direcciones visuales exploradas para domina-js con impeccable (2026-11-20). La elegida para domina-js es **Pizarrón y tiza amarilla** (`r1-pick`). Las demás quedan guardadas para las webs hermanas (C#, SQL, Python).

Cada carpeta tiene:
- `boceto.html`: primera pantalla a 1440×900, para abrir en el navegador.
- `captura.png`: captura del boceto, si existe.
- `ficha.json`: tesis, paleta, materiales y riesgo.
